# 아키텍처 검증 증거 계획

상태: **미실행 / 측정 결과 미첨부**. 이 문서는 시험 설계이며 통과 보고서가 아닙니다.

## 증거를 남기는 단위

시험 결과에는 코드 커밋, 정책·스키마·SDK·모델 버전, 운영체제·자원, 데이터셋 버전, 실행 시각, 기대 결과, 실제 결과, 한계와 재현 명령을 기록합니다. 의뢰인 원문과 자격 증명은 넣지 않고 가상 자료·최소 식별자로 검증합니다.

| ID | 검증할 주장 | 시험 방법 | 기록할 결과 |
|---|---|---|---|
| ISO-01 | 사건별 접근 경계 | 테넌트 A 사용자의 B 파일·사건 ID 접근, 동일 로펌의 미배정 사건 접근 | 거부 응답, 허용 루트 외 열기 시도 여부, 반환 결과·출처의 범위 |
| ISO-02 | 우회 경로 차단 | Python 직접 호출, 위조·만료·다른 대상 토큰, 경로 조작·심볼릭 링크 | 인증·경로 해석 결과, 파일 접근 이전 차단 여부 |
| ISO-03 | 주변 저장소도 분리 | 캐시·임시 평문·로그·백업 복원·권한 해제 후 재조회 | 타 사건 원문 포함 여부, 삭제·권한 변경 후 재등장 여부 |
| BUD-01 | 원자적 예산 예약 | 잔액에 가까운 요청을 동시에 실행하고 같은 ID 재전송 | 승인 합계·예약 잔액·중복 유료 호출 수 |
| BUD-02 | 실행 중 한도 집행 | 반복·재시도·모델 전환·출력·기한 상한을 초과시키기 | 허용/실제 단계 수, 이후 호출 차단, 취소 전달 시각 |
| BILL-01 | 사용량 정산 추적 | 실패·취소·타임아웃·usage 미수신·JSON 오류를 주입 | 예약·실제·추정·미확정 비용, 공급자 대조 차이, 중복 종료 여부 |
| QUAL-01 | 한국어 근거 품질 | 버전이 고정된 가상 사건 평가집, 정답 문서 ID를 먼저 확정 | Recall@k, 출처 오류, 금액·날짜·부정·충돌 진술 누락 |
| HITL-01 | 검토 재개 경계 | 대기 중 권한 해제·초안 수정·자료 변경·서버 재시작 | 이전 승인 재사용 여부, 재인증·재예약, 오래된 초안 처리 |
| COST-01 | 운영 부담 감소 | 같은 자료·질문·호출량·보관 기간으로 기준 구성과 비교 | CPU·메모리·스토리지·백업·모델·임베딩·운영 시간과 총비용 |
| REC-01 | 무결성·복구 | 저장 중 중단·파일 잠금·재개방·암호화 백업 복원 | 누락·중복, 검색 일치, 복구 시간, 실패와 수동 작업 |

## 비교 결과를 해석하는 규칙

- 시험을 통과한 범위·데이터·버전에 대해서만 결과를 서술합니다. 유한한 시험으로 모든 침해 가능성이 없다고 증명하지 않습니다.
- 검색 지연과 전체 응답 지연을 구분하고 p50/p95, 작업량, 자원을 함께 기록합니다.
- 자체 모델·파일 구성을 경쟁 서비스의 공개 챗 화면과 단순 비교해 보안 우위를 주장하지 않습니다. 제품·버전·설정·권한·운영 범위를 일치시킬 수 있는 항목만 비교합니다.
- 검색 DB 요금 감소와 전체 운영비 감소를 구분합니다. 실제 비용이 드는 자원을 누락해 0원으로 계산하지 않습니다.
- 통과하지 못한 항목과 미확정 공급자 비용도 보고서에 남깁니다.

## 결과 기록 양식

```text
시험 ID:
상태: NOT_RUN / PASS / FAIL / INCONCLUSIVE
코드 커밋 및 정책·SDK·모델 버전:
데이터셋·환경·실행 시각:
재현 절차:
기대 결과:
관측 결과와 원본 증거 위치:
한계·미확정 항목:
```

결과가 생기면 비밀정보를 제거한 시험 로그·평가표·비용 대조표를 함께 첨부하고 메인 README의 주장과 연결합니다.
